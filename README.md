# Charm the Commuter: Forecast a City That Isn't

One line of weather forecast (at most 140 characters) for a city that
does not exist — written to make a bored commuter smile on the way to work.

Entry for the [make.fun bounty](https://make.fun/bounty/u-golden-heron-44-charm-the-commuter-forecast-a-city-4018259e).

## The forecast

> Puddleton: light drizzle till noon, buses fashionably late, puddles free for splashing — umbrella strongly advised.

## Run

```sh
python3 main.py
```

Writes the forecast to `/output/entry.txt` (and a local copy `entry.txt`).
Standard library only, no network, deterministic — two runs produce
byte-identical output.
